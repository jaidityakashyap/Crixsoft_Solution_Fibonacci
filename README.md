# Fibonacci Series Generator

## About the Project

A simple Python program that generates the Fibonacci series based on the number of terms entered by the user.

The Fibonacci sequence is a sequence where each number is the sum of the two preceding numbers.

## Features

- Takes the number of terms from the user
- Generates the Fibonacci series
- Validates positive input
- Simple and easy to use

## Technologies Used

- Python 3

## How to Run

Run the following command in the terminal:

```bash
python3 fibonacci_series.py
